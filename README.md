# EV1平台

低空行业资讯交流 + 无人机商城 / 研究室。界面为简体中文。资讯会自动更新公开报道，站长也可以自己发布。研究室的科普和资料评测、以及四篇官方资讯来自已核对的公开资料。商城商品和比赛栏目里未替换的条目仍是示例内容。

## 技术栈

- Vite 8 + React 19
- React Router 7（前端路由）
- 本地 JSON/JS 数据：`src/data/content.js`；资讯列表由 `public/data/news.json` 提供
- 购物车为浏览器端状态（Context + localStorage），无后端

## 本地运行

```bash
npm install
npm run dev
```

默认地址：http://localhost:5173/（使用 Hash 路由，如 `/#/news`）。

若要得到可在浏览器里直接双击打开的单文件页面：

```bash
npm run build
```

构建结果在 `dist/index.html`，已内联全部 JS/CSS，可用 `file://` 打开，无需 Node 或本地服务器。

生产预览：

```bash
npm run preview
```

## 页面

- `/` 首页
- `/news` 行业资讯（四个分类标签 + 详情 `/news/:id`）
- `/shop` 无人机商城（筛选、卡片、详情 `/shop/:id`、客户端购物车）
- `/lab` 研究室（技术研究 + 产品评测，详情 `/lab/:id`）

视觉方向为街机涂鸦风，主色为醒目黄，标志使用文字字标「EV1平台」，不使用图片 Logo。

## 怎样发布一条资讯

不用写代码，也不用打开电脑上的命令行。用你的 GitHub 账号做下面这些事就行。

1. 打开网站的「行业资讯」页：https://zhaiwengfc.github.io/ev1-1/#/news
2. 点击黄色按钮 **发布资讯**。它会打开 GitHub 的新建 Issue 页面，并选中「发布资讯」表单。
3. 如果 GitHub 要求登录，用这个仓库的主人账号登录。协作者也可以发。其他人发了也不会出现在网站上。
4. 填写：
   - **标题**：网站上要显示的标题。页面最上面的 Issue 标题可以写成同样的文字。
   - **分类**：四个里选一个（政府政策、科技创新与供应链、比赛信息、无人机新品发布）。
   - **摘要/正文**：写给读者看的文字，普通换行即可。
   - **原文链接**、**图片链接**：可以不填。要填就粘贴以 `https://` 开头的网址。
5. 点提交（Create / 创建）。
6. 等几分钟再刷新网站。你的内容会出现在资讯最上面，并带 **官方发布**。首页的「最新资讯」也会一起更新。有时要再等大约十分钟，页面缓存才会换成新的。
7. 想改文字：打开那条 Issue，编辑后保存。网站会再更新一次。
8. 想从网站撤下：把那条 Issue **关闭**。不要删仓库里的代码。

自动收集的公开报道大约每 3 小时更新一次，不用你操作。那些条目会写出来源，并可以打开原文。它们没有「示例内容」标记。商城里的商品和研究室里的评测仍然是示例。

如果提交时提示缺少名为「资讯」的标签：打开仓库的 Issues → Labels → New label，名称正好写成 `资讯`，然后重新提交。平时不用做这件事，自动任务会尝试创建这个标签。

如果改了 Issue 之后网站一直不变：打开仓库的 Actions，看「更新资讯并发布到 GitHub Pages」是不是成功。第一次使用如果失败，到 Settings → Actions → General → Workflow permissions，选中 Read and write permissions，再回到 Actions 里重新运行那次任务。Pages 的来源需要保持为 GitHub Actions。
